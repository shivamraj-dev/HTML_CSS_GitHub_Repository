# Assignment 15: Responsive Pages with Media Queries

**Course:** B.Tech CSE — Second Year  |  **Lab:** HTML and CSS Introduction Lab (BCS352)

## Aim

Cards stack on phones and sit side by side at 600px and above.

## Tasks and expected output

### Task 1 — Mobile-first cards
Cards stack on phones and sit side by side at 600px and above.

### Task 2 — Responsive image
Image scales to the available width with height:auto.

### Task 3 — Responsive text
Body uses 1rem; h1 changes from 1.5rem to 2.5rem at 600px.

## How to run

Open the relevant `.html` file in a modern web browser. For local preview from the repository root, you can also run `python -m http.server 8000` and visit `http://localhost:8000`.

The expected visible result for each task is described above. Capture your own browser screenshots after running each page if your instructor requires screenshot evidence. No fabricated browser screenshots are included.
